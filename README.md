# Guess Word

A simple and fun word guessing game.

## 🎮 Play

**Play Online:**

- [简体中文](https://testgame.moosasa.com/guess-word/?lang=zh-CN)
- [繁體中文](https://testgame.moosasa.com/guess-word/?lang=zh-TW)

## ✨ Features

* 30 random questions per game
* Simple left / right answer selection
* Score tracking
* Weekly ranking
* Sound effects and background music
* Mobile-friendly
* Supports multiple languages

## 🌍 Languages

* 繁體中文
* 简体中文

## 🛠 Tech Stack

* Cocos Creator 3.8
* TypeScript
* HTML5
* REST API
* Google Analytics 4
* Google AdSense
