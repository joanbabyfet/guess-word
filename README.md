# Guess Word

A simple and fun word guessing game.

## 🎮 Play

**Play Online:**
https://testgame.moosasa.com/guess-word/

## ✨ Features

* 30 random questions per game
* Simple left / right answer selection
* Score tracking
* Weekly ranking
* Sound effects and background music
* Mobile-friendly
* Supports multiple languages

## 🌍 Languages

* 繁體中文
* 简体中文
* English

## 🛠 Tech Stack

* Cocos Creator
* TypeScript
* HTML5
* REST API
* Google Analytics 4
* Google AdSense
